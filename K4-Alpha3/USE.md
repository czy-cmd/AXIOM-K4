## 简介

AXIOM 是一款极简打字训练系统，型号 K4，当前版本 Alpha 3。它把练习、关卡、人机对战与成绩记录收进同一套冷峻界面：文章可自由选读，逐字着色实时反馈；人机对战提供 minimal 到 xhigh 五档难度，你的进度与对手进度同屏可见。支持浅色、深色、跟随系统三套主题，以及 exe、网页、手机三种打开模式；网页版可离线双击运行，也能发布到 GitHub Pages。内置错字本、成绩导出、文章收藏与更新日志；调试模式需口令进入，全程不写存档。少一点花哨，多一点准确——AXIOM 只保留打字本身。

**本轮追加（2026-11-21）**：难度滑块改为连续拖动 + 缓动吸附；调试密码固定 `devczy` 且删除设置/修改按钮；打字页新增「开始输入 / 后退 / 前进 / 返回 / 全屏」实体按钮；登录页新增「调试模式」无存储会话（仅练习 + 人机对战 + 开发者面板「导出 log」）；`测试版/` 下每个历史版本目录都补了 `CHANGELOG.md`，只写相对上一版的更新。

| 项 | 现状 |

| 文本 | `PRACTICE_TEXTS` 5 篇（每篇约 500 字）；`LEVEL_CATEGORIES` 5 类 × 4 段（关卡循环成 20 关） |

| 存档 | `typing_userdata.json`（用户真实数据，**只读**）；`typing.db` 代码中未引用，遗留文件，**不动** |
| 配色 | 模块级全局常量 `BG/PANEL/FG/…` 硬编码，散落全文件；改主题必须先收口 |

**核心结论**：主题能力是本版最大改造量，必须先做 `theme.py` 色板收口，再做其余 UI 功能，避免二次返工。

## 2. 需求逐条落地方案

### R1 登录界面改版（上网参考结论）

参考来源：Adminator 2026 分栏登录、Minimal Card with Floating Labels、Terminal Login、OpenCodex 单色 Infra Console 主题（2026）。

| 设计点 | 落地动作 |
| --- | --- |
| 布局 | 左侧品牌栏（约 38%）：大号 `AX.` 等宽字，副标 `MODEL K4 · ALPHA 3`，顶行 `AXIOM / TYPING SYSTEM`，一行 slogan、细线几何装饰，**logo 靠左栏顶部左对齐**；右侧表单区：窄卡片、垂直居中。窗口 <940px 时品牌栏收为顶部窄条 |
| 表单 | 浮动标签式用户名/密码（焦点时标签上移）、密码显示/隐藏切换、回车提交、失焦即时校验；错误文案内联显示在字段下方，不用弹窗 |
| 入口 | 「登录 / 注册」为主次按钮；游客、无痕降为带分隔线的文字链接，不再用彩色块，降低视觉噪音 |
| 质感 | 单色底 + 发丝边框 + 单层柔阴影；左栏径向左上微光（Canvas 渐变模拟），**不做毛玻璃**（Tkinter 无 backdrop-filter，硬做会掉帧） |
| 复用 | 所有颜色取自 `theme.py`，登录页不得出现硬编码色值 |

验收：三主题下登录页可读、无错位；校验提示不弹窗；Tab 顺序为 用户名 → 密码 → 显隐 → 登录 → 注册 → 游客 → 无痕。

**新增：注册/登录后的用户协议**（用户新想法）
- 登录或注册成功、进入主菜单**之前**插入一次协议确认层，样式与其他产品常见的一致：标题《用户协议与数据说明》、可滚动正文、底部「同意并继续」主按钮 + 「暂不使用」次按钮。
- 每个账号只需确认一次；结果写入存档键 `agreement_accepted`。拒绝则返回登录页，不进入主菜单。
- 文案要点（纯说明、无强制条款）：数据只存在本机/浏览器、不上传；无痕模式不保存；标点与主题偏好本地保存；程序含 AI 生成内容请注意辨别；调试模式需密码。
- 文案集中在 `web/articles.js` 的 `K4_AGREEMENT`，用户如有原文可整段替换，不改逻辑。

### R2 联机改版 → 人机对战 + Codex 风格难度滑块

**命名**：菜单卡片「人机对战」；页面标题 `VERSUS / 人机对战`；不再出现「联机」「匹配」「房间」字样（纯本地，避免误导）。

**难度定义（沿用 Codex `reasoning effort` 五级命名，带逼格说明）**：

| 档位 | 代号 | 中文 | 机器人速度（字/秒） | 说明文案 |
| --- | --- | --- | --- | --- |
| 1 | `minimal` | 热身 | 0.9 – 1.3 | 只做最少的活 |
| 2 | `low` | 稳速 | 1.5 – 2.1 | 轻载运行 |
| 3 | `medium` | 基准 | 2.3 – 3.1 | 默认平衡点 |
| 4 | `high` | 高压 | 3.4 – 4.4 | 多线并行推进 |
| 5 | `xhigh` | 极限 | 4.6 – 6.2 | 全力推理，不留余量 |

- 默认第 3 档；滑块为 5 个离散档位，键盘 ← → 可调。
- **顺滑吸附（已实现）**：`step=0.01` 连续拖动，轨道填充与档位文字实时跟随；松手 / 触屏抬起 / 按键松开时以 260ms 缓动动画移到最近整数档位，没有到位置也会自动归位，档位写入存档。
- 视觉：Codex 风格轨道、填充随主题反转、圆形滑块带柔光；上方等宽字大号档位名（如 `03 / MEDIUM`），下方一行说明。**档位浮标与 5 个刻度按滑块半径修正坐标**（首尾内缩 10px），文字、刻度、滑块中心三者对齐；不用卡通图标、不用花哨动画。
- 机器人数量固定 12（可选 8/12/16），避免 Alpha2 的 20~50 人刷屏；名字改为 `AGENT-01 … AGENT-12`，自己显示为 `YOU`。
- **进度同时可见**：新增 `race_hud.py`，自己 `YOU` 的进度块在 HUD 左侧用主题强调色高亮并固定置顶；`OTHER AGENTS / 其他进度` 整体靠右，LEADER 与每个机器人的数值右对齐、进度条从右向左生长。这样自己和对手同屏，且对手信息明显居右。
- 原有排名表保留但降为次要信息；结算页显示「名次 / 难度 / 胜过的 Agent 数」，记录写入 `mode=人机对战`。
- 难度参数集中在 `core/difficulty.py`，改数值不动 UI 代码。

验收：拖满 5 档各跑 10 秒，机器人速度单调递增；你自己和至少一个对手的进度条始终同屏可见；退出后无残留定时器。

### R3 增加内置文章

- 迁移 Alpha2 的 5 篇到 `core/articles.py`，标题与正文一字不改。
- 新增 **12 篇**，每篇 350–600 字，题材分散：科学常识、自然观察、历史片段、艺术与审美、运动与健康、编程思维、城市乡村、亲情友情、时间管理、阅读方法、技术伦理、专注力训练。
- 其中 **4 篇为时政/政策常识科普**（用户指定）：如《读懂政府工作报告》《行政许可法小常识》《人大代表建议如何办理》《全民国家安全教育日》。内容只做公开制度与常识讲解，依据官方公开信息表述，不评论具体事件与人物。
- 字段统一：`id / title / category / tags / text`；`category` 供筛选（`成长 / 人文 / 科普 / 生活 / 时政`），`tags` 供错字本生成专项练习时标注。
- 全部原创改写，不引入版权文本；保留启动器「含 AI 生成内容，请注意辨别」提示。
- `LEVEL_CATEGORIES` 原样迁到 `core/levels.py`，**关卡 ID 与顺序不变**，保证老玩家解锁进度可用。
- 练习选文页增加分类筛选（全部 / 人文 / 科普 / 生活 / 成长）+ 篇数字数显示；选文列表用 Canvas 滚动，沿用 Alpha2 已验证的滚动写法。

### R4 自拟 3 条更新（本次新增功能）

1. **错字本（Mistake Notebook）**：练习/对战结束时收集连续打错的字符与所在词，按错误次数排序；支持「用错字生成练习」——把错字串接成 200 字专项文本重新练。只存字符与计数，不存输入历史。
2. **成绩导出（Result Export）**：设置页一键把历史成绩导出为 CSV（日期 / 模式 / 难度 / 分数 / 等级 / 准确率 / 速度）；导出走系统保存对话框，不自动写文件。
3. **文章收藏（Favorites）**：文章列表可星标，练习选文页可只看收藏；收藏状态存在 `user_data.json`，不影响内置文章本身。

### R6 调试模式（设置页开关 + 密码保护）

- 设置页增加 `Debug Mode` 开关，默认 **关**，状态存 `user_data.json` 的 `debug` 字段（不写入 Alpha2 旧档）。
- **密码保护（已按新决定改）**：固定口令 `devczy`，写在 `web/config.js` 的 `debug_password`；每次开启只需验证，**删除「设置调试密码」「修改调试密码」按钮**，设置页不再出现改密入口。旧存档里的 `debugSalt / debugHash` 读取时自动丢弃。
- 打开后：①顶部状态条显示 `FPS / tick / AI 速度 / 当前视图`；②对战 HUD 显示机器人真实 speed 值；③设置页出现「诊断信息」按钮（Python 版本、屏幕缩放、数据路径、文章数、存档大小）；④错误写入同级 `debug.log`（正常模式只弹友好提示，不写日志）。
- 快捷键 `F9` 切换调试覆盖层；`F10` 复制诊断信息到剪贴板。关闭开关后覆盖层与日志写入全部停止。
- 调试模式**不得**绕过存档读写校验，也不得提供清空他人数据的按钮。

**登录页「调试模式」（新增，与游客 / 无痕并列）**
- 输入固定口令后进入 `session.mode = 'debug'`：主菜单只保留「练习」「人机对战」两张卡片 + 一个 `DEVELOPER PANEL`。
- 开发者面板只放一个按钮「导出 log」（`k4_debug.log`），其余信息只读。
- 全程无存储：`persist()` 对 `debug` 会话直接返回，成绩、错字、收藏、主题、模式切换都不落盘；会话结束不留痕。
- `showView()` 拦截关卡 / 纪录 / 设置 / 更新日志，避免从其它入口绕进受限页面。

### R7 三种风格：浅色 / 深色 / 跟随系统

- `core/theme.py` 定义 3 套 Palette（bg / panel / fg / dim / border / accent / success / danger / text_pending / text_correct / text_wrong / text_skip），`light` 沿用 Alpha2 米白配色，`dark` 用深灰底 + 低饱和蓝灰强调。
- `system` 通过 Windows 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme`（ctypes 调 Advapi32，无第三方依赖）读取；窗口获得焦点时复核，或每 30 秒轮询一次，变化时触发全量重绘。
- 全程序禁用硬编码色值；`App` 持有 `palette`，切主题调用 `rebuild_shell()` 重建当前视图（Alpha2 的 View 全部在 `__init__` 里建控件，局部改色不可靠）。
- 网页模式用 CSS 变量 `data-theme="light|dark|system"`，`prefers-color-scheme` 对应跟随系统。
- 主题选择存 `user_data.json`；首次启动默认 `system`。

### R8 界面简洁

### R9 网页模式（三种打开模式 + 网址优先 / 本地兜底）

**打开链路**（用户指定）：exe 启动 → 读 `config.json` 的 `remote_url` → 默认用系统浏览器打开 GitHub 网址 → 连接失败/超时则显示提示 **「网络故障，尝试打开本地html中……」** 并打开 `web/index.html`。网址暂空，用户提供后填入；本地 HTML 始终保留可离线双击使用。

**设置页「打开模式」三选一（用户指定）**，决定布局与存档介质：

| 模式 | 布局适配 | 存档 |
| --- | --- | --- |
| exe 打开模式 | 桌面宽屏，右侧固定对战 HUD，键盘提示完整 | 本机 `data/user_data.json` |
| html 打开模式 | 浏览器宽屏，HUD 可折叠，键盘 + 鼠标 | 浏览器 `localStorage`，可导出 JSON 备份 |
| 手机端打开模式 | 单列窄屏，HUD 移到文本下方，按钮 ≥44px，隐藏输入域唤起软键盘 | 浏览器 `localStorage`，可导出 JSON 备份 |

- 三种模式**都允许写入存档**（用户确认）；无痕登录与登录页「调试模式」除外，这两种会话不落盘。
- 网页功能与程序对齐：选文（同源文章池）、5 分钟计时、逐字着色、← → 移动、实时分数/准确率、难度滑块、对手进度条、结算等级、协议确认、主题、调试密码。
- `file://` 下浏览器禁止 `fetch` 本地 JSON → 文章以 `web/articles.js` 全局变量提供；新增文章由同一数据源生成 `core/articles.py` 与 `web/articles.js`，避免两份不同步。
- 兼容 Edge / Chrome / 手机浏览器，不引外部 CDN，双击 HTML 即可离线使用。
